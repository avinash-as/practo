AI-Powered Content Creation System

Founder idea → research → copy → design → editable carousel → review → export

1

Founder enters a raw idea

A one-line topic, angle or hook. e.g. "5 AI tools every student should know".

Notion / Google Doc / Form
↓
2

AI researches & structures

LLM (ChatGPT/Claude/Perplexity) expands the idea: audience, key points, slide outline, hook, CTA.

ChatGPT · Claude · Perplexity
↓
3

Generate headlines & slide copy

Slide-by-slide copy: title, body, micro-copy, hashtags, caption. Output as structured JSON/Markdown.

Claude / GPT-4o with prompt template
↓
4

Visual direction, layout & design

AI suggests palette, typography, layout per slide. Rendered via Canva template or code (Pillow/HTML→image).

Canva · Figma · Python/Pillow · HTML→PNG
↓
5a

Editable carousel

Canva/Figma file the founder can tweak (text, colors, images) in minutes.

Canva · Figma
5b

Ready-to-publish PNGs

Exported 1080×1080 slides, named and ordered, plus caption .txt.

Export / cloud storage
↓
6

Founder reviews & minor edits

Swap words, fix facts, adjust branding. Approve or request regeneration of a slide.

Canva / Figma editor
↓
7

Export & publish

Download final assets; schedule via Buffer/Later/Meta Business Suite; auto-post to IG & LinkedIn.

Buffer · Later · n8n/Make

Automation layer (connects the steps)

Trigger

Founder submits idea via Notion form / Google Form / Slack command.

Orchestration

Make or n8n workflow calls LLM API → parses JSON → generates images → uploads to Drive/Canva.

Notification

Slack/Email ping: "Carousel ready for review" with preview link.

Storage

Google Drive folder per post: slides + caption + metadata.

Publishing

Scheduled auto-post to Instagram & LinkedIn via Buffer/Meta API.

Analytics

Track engagement; feed top performers back as prompts for next ideas.
